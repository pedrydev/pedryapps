# Glossary Map

## Contexts

- [Global](./GLOSSARY.md): the container app and the language shared across mini-apps
- [Todos](./mini-apps/todos/GLOSSARY.md): capturing, categorizing, ordering and checking off personal to-dos on a board, each with a do-on date
- [Notifications](./mini-apps/notifications/GLOSSARY.md): collecting in-app messages posted by mini-apps and showing their unread count in the menu bar

## Relationships

- **Global → mini-apps**: the global glossary names each mini-app; a mini-app's glossary owns its domain terms
